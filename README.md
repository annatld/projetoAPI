## Projeto de uma API RESTful 
Desenvolvida com Spring Boot 3 e Java 17, hospedada na plataforma Railway. A API inclui funcionalidades de autenticação e autorização, gerenciamento de dados com um banco de dados relacional e documentação interativa com Swagger.
O objetivo deste projeto é [descrever o propósito, como uma plataforma de gerenciamento de usuários, e-commerce, etc.

## 💻 Tecnologias utilizadas

- Spring Boot 3
- Java 17
- Railway (hospedagem)
- Banco de dados relacional
- Swagger (documentação)
